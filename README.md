# 🇺🇦 VeteranPath Lviv (ВетеранШлях: Львівщина)

> **Платформа комплексної реінтеграції ветеранів: від демобілізації до впевненого цивільного життя.**

Проєкт поєднує **детермінований юридичний рушій правил** (нуль галюцинацій щодо законів і пільг) із можливостями **Google Gemini AI** (автоматичний парсинг вільної розповіді ветерана, адаптація бойового досвіду для резюме та юридичний RAG-асистент).

---

## 🌟 Тривимірне позиціонування (Конкурсний фокус)

1. **Human-First (Для ветерана):**
   * **Повна анонімність:** вхід без реєстрації, без номерів телефонів та паспортів.
   * **Покрокова дорожня карта:** структурована за етапами (1-й тиждень, 1-й місяць, 3 місяці, довгостроково) з адресами ЦНАПів та списками документів.
   * **«Військовий перекладач»:** перетворює ВОС та військові обов'язки на готові формулювання для цивільного CV та виділяє професії з найвищим метчем.
   * **Локалізація у Львові:** пряма інтеграція послуг центрів **UNBROKEN (Незламні)**, **Superhumans Center**, Ветеранського простору та виплат ЛМР.

2. **GovTech & Муніципалітет (Львівська ОВА / ЦНАП):**
   * **Анонімна теплова карта потреб:** скільки людей потребує реабілітації, скільки шукає роботу, скільки планує відкривати бізнес.
   * Координація муніципальних програм, компенсацій та ваучерів центру зайнятості.

3. **B2B & Економічна реінтеграція (Роботодавці та Інвестори):**
   * Каталог перевірених роботодавців із ветеранськими менторськими програмами (SoftServe, Meest, Kormotech).
   * Безпечна дія «Зацікавило»: прямий контакт кандидата з рекрутером лише за індивідуальною згодою.
   * Грантовий трек: підтримка подання на «єРобота: Власна справа» до 1 млн грн.

## 🛡️ Безпека та захист від витоку ключів (Security First)

Проєкт спроектований так, щоб унеможливити інциденти на кшталт **Neon Credential Exposure Alert**:
* У репозиторій додано розширений `.gitignore`, який блокує будь-які `.env`, `*.key` чи локальні бази даних.
* Всі секрети читаються через `pydantic-settings` виключно зі змінних середовища.
* **Smart Database Fallback:** якщо змінна `DATABASE_URL` не задана, бекенд автоматично піднімає безпечну вбудовану базу даних SQLite, що гарантує працездатність без помилок.
* **Offline Mock Fallback:** якщо `GEMINI_API_KEY` відсутній або зник інтернет, система автоматично перемикається в офлайн-режим зі збереженими сценаріями (наприклад, для демо-ветерана Андрія).

## 🚀 Швидкий запуск локально

### 1. Бекенд (FastAPI)
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp ../.env.example .env
uvicorn app.main:app --reload --port 8000
```
API документація буде доступна за адресою: `http://localhost:8000/docs`

### 2. Фронтенд (Next.js)
```bash
cd frontend
npm install
npm run dev
```
Додаток відкриється за адресою: `http://localhost:3000`

---

## 🐳 Деплой на сервер (Docker Compose)

Для швидкого розгортання на VPS або хмарному сервері перед конкурсом:

```bash
docker compose up -d --build
```

Система підніме фронтенд на порту `:3000` та бекенд на порту `:8000`.

## 👥 Сценарій Демо для пітчу перед журі

1. **Крок 1 (Лендінг):** Натисніть *«Скласти мій персональний план»*.
2. **Крок 2 (Онбординг):** Оберіть вкладку *«Вільним текстом»* та клікніть підказку *«Вставити демо-сценарій "Ветеран Андрій"»*. Натисніть *«Розпізнати параметри»*. ШІ миттєво визначить статус, потребу в реабілітації коліна через UNBROKEN та ціль (робота/кав'ярня).
3. **Крок 3 (Дорожня карта):** Побачите відсортовані за пріоритетом кроки (отримання витягу, огляд в UNBROKEN, виплата ЛМР). Позначте крок прапорцем — прогрес-бар автоматично оновить відсоток.
4. **Крок 4 (Резюме):** Перейдіть у *«Мій досвід»*, вставте опис служби командира відділення. Отримайте готові формулювання для CV (лідерство, логістика, антикризове управління).
5. **Крок 5 (Вакансії та згода):** Перейдіть у вакансії, натисніть *«Зацікавило»* на позиції Meest або SoftServe та передайте контакт.
6. **Крок 6 (Кабінет партнера):** Перейдіть у *«Кабінет партнера / GovTech»* та покажіть журі, що новий лід вже з'явився у таблиці роботодавця, а теплова карта потреб громади оновилася.
